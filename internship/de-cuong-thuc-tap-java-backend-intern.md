**8. Công việc và yêu cầu thực hiện:**

Trong thời gian thực tập, sinh viên thực hiện đào tạo và thực hành theo định hướng Java Backend Intern. Nội dung thực tập tập trung vào việc củng cố kiến thức nền tảng Java, làm quen với quy trình phát triển backend trong dự án thực tế, sau đó áp dụng vào đồ án xây dựng hệ thống quản lý phòng gym.

Các công việc chính gồm:

- Ôn tập và củng cố Java Core: lập trình hướng đối tượng, collection, exception handling, generic, stream, date/time API và các nguyên tắc viết mã rõ ràng, dễ bảo trì.
- Tìm hiểu quy trình phát triển backend: phân tích yêu cầu, thiết kế database, thiết kế REST API, tổ chức mã nguồn, kiểm thử API và quản lý source code bằng Git/GitHub.
- Nghiên cứu và thực hành Spring Boot: xây dựng REST API, validation, xử lý lỗi tập trung, cấu hình môi trường, Spring Data JPA/Hibernate và kết nối PostgreSQL.
- Tìm hiểu các kiến thức cần thiết về bảo mật backend: authentication, authorization, JWT, phân quyền người dùng và bảo vệ các API quan trọng.
- Phân tích nghiệp vụ hệ thống quản lý phòng gym, bao gồm quản lý khách hàng, gói tập, thời hạn gói, thanh toán, công nợ cơ bản, lịch tập/PT và các báo cáo vận hành.
- Xây dựng từng phần backend cho dự án `gym-management-system` theo hướng có thể mở rộng, dễ bảo trì và phù hợp với quy mô phòng gym nhỏ.
- Viết tài liệu kỹ thuật cơ bản, tài liệu API, ghi nhận kết quả thực hiện và chuẩn bị báo cáo thực tập.

Yêu cầu đạt được:

- Nắm được kiến thức nền tảng để tham gia phát triển backend bằng Java/Spring Boot.
- Xây dựng được cấu trúc dự án backend rõ ràng, có kết nối PostgreSQL và có khả năng phát triển tiếp.
- Hoàn thành các API cốt lõi cho hệ thống quản lý phòng gym ở mức phù hợp với thời gian thực tập.
- Biết kiểm thử API, xử lý lỗi, kiểm soát dữ liệu đầu vào và quản lý mã nguồn trên GitHub.
- Có báo cáo tổng kết quá trình thực tập và sản phẩm minh họa kết quả thực hiện.

**9. Hình thức báo cáo và yêu cầu thực hiện:**

Hình thức báo cáo:

- Báo cáo tiến độ định kỳ với người hướng dẫn trong quá trình thực tập.
- Báo cáo kết quả học tập, nghiên cứu và phát triển sản phẩm theo từng giai đoạn.
- Trình bày sản phẩm demo backend của hệ thống quản lý phòng gym.
- Nộp báo cáo thực tập theo quy định của Khoa Công nghệ Thông tin, Trường Đại học Quy Nhơn.

Sản phẩm dự kiến:

- Mã nguồn dự án backend Java/Spring Boot được quản lý trên GitHub.
- Cơ sở dữ liệu PostgreSQL và tài liệu thiết kế database ở mức cốt lõi.
- Bộ REST API phục vụ các nghiệp vụ chính của hệ thống quản lý phòng gym.
- Tài liệu mô tả API hoặc collection kiểm thử API bằng Postman/HTTP client.
- Báo cáo thực tập tổng hợp quá trình học tập, triển khai và kết quả đạt được.
